# strig brand

The mark for strig, the new name of the authorization library. The mark is called Corte: a full moon with a bite
taken out of it, and the fangs are the shape of the missing piece.

## Files

| Path | What it is |
|---|---|
| `strig-brand-sheet.html` | The brand sheet: symbol construction, minimum sizes, wordmark, lockups with clear space, palette with measured contrast, and usage rules. Open it through a local server, because it fetches `fonts/Cinzel-Medium.ttf`. |
| `svg/strig-simbolo-*.svg` | Symbol in the light, dark and one-colour variants. `viewBox` 64 × 64. |
| `svg/strig-wordmark-*.svg` | Wordmark for light and dark backgrounds. |
| `svg/strig-lockup-horizontal-*.svg` | Symbol and wordmark side by side: light, dark and white. |
| `svg/strig-lockup-empilhado-*.svg` | Symbol above the wordmark, for light and dark backgrounds. |
| `fonts/Cinzel-Medium.ttf` | Cinzel Medium (500), the wordmark typeface. |
| `licenses/Cinzel-OFL.txt` | SIL Open Font License 1.1 for Cinzel. |

The SVG letters are outlined paths, so the files render without the font installed. The "dark" variants have a
transparent background and are meant for dark surfaces.

## Palette

| Role | Hex |
|---|---|
| Primary, light background | `#B01030` |
| Primary, dark background | `#FF5E70` |
| Support (links, charts) | `#996C6C` |
| Light background | `#FFFFFF` |
| Dark background | `#0A0A0A` |
| Ink on light | `#111111` |
| Ink on dark | `#F2F2F2` |

The sheet shows the measured contrast of each pair. Text needs 4.5:1, while the symbol and the support colour need 3:1.

## Rules

- Below 24 px of height, use the symbol alone. The horizontal lockup does not go smaller than that.
- Keep Cinzel for the wordmark and do not swap it for a similar inscription typeface.
- No dripping blood and no other gore on the fangs.
